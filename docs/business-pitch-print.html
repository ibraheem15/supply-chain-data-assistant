Business Problem03 / 08

Dashboards ask people to already know the question.

Fixed filters, fixed views

If a question wasn't anticipated in the design, the dashboard can't answer it.

No connection across data

Related records across screens still have to be pieced together by hand.

Legacy system, no API

The data is protected and any new interface must go through an approved path.

New question, new screen

Every unplanned question turns into a change request, and more training.

The Solution05 / 08

Ask, don't query.

Driver / ops user
Agent
DB (read-only) + SOPs
Answer
Any temperature issues on Route RT-2291 right now?
IOT_TEMP_C is 6°C above threshold. SOP-014 requires isolating the pallet and notifying the route owner within 30 minutes. Drafting the notification now.

Minutes, not an escalation chain.

The Conversation Continues06 / 08

Context carries the follow-up.

Has this route had temperature problems before?
Yes — 3 times in the last 90 days, all in the same trailer. Disruption likelihood for this route is trending up: 0.62 → 0.78.

No new screen, no query language — the user just kept talking, and the agent kept the thread.

Governance & Security07 / 08

Access is scoped and provable, not assumed.

Least-privilege role

The agent's database login can only SELECT. It cannot insert, update, or delete — enforced by the database, not application code.

Governed views

The agent queries curated views, not raw tables, exposing only approved columns and rows.

Immutable audit log

Every query the agent runs, and every answer it gives, is written to an append-only log for review.

Role clarity

Access follows the requester's own role. The agent never sees more than the person asking already could.
